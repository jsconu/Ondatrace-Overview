How it works

1. Connect

Sign in to the tools you already have

Connect each tool with a normal sign-in. Record your project meetings too, because many decisions and new dates are only ever said out loud.

2. Connect the dots

It matches up the same work

It recognizes the same project in different tools and finds projects nobody set up. You confirm the links.

3. Decide

Each person sees what needs them

Every item says why it matters and suggests what to do next.

Works with the tools you already use: Jira, Kantata, Salesforce, Smartsheet, Slack, Microsoft Teams, Outlook, Google and Microsoft calendars, Zoom, Webex and Google Meet.

How our project management agent works

The agent does the reading and the writing. Fixed rules make the calls that have to come out the same every time, and a person approves anything with real consequences.

Reads

Turns messy messages into facts

It reads messages, tickets and meeting transcripts and pulls out the promises and decisions in them. Each fact links back to where it came from.

Judges

Rules decide, the agent explains

Project health and what needs attention come from fixed rules built with practicing project managers. The agent writes the explanation and the next step, but it can't change the result.

Acts

You approve anything that matters

It saves evidence on its own, and it can make small task updates if you allow it. Anything bigger waits for a person, such as moving a committed milestone or sending a message.

Runs on its own

Works between your meetings

It checks your tools every 15 to 30 minutes and picks up Slack messages within about a minute. It only reruns the analysis where something changed, so quiet projects stay quiet.

Stays in its lane

The app enforces permissions

The application decides what each person can see, and the agent can't change that. If a finding comes from someone's private email, people who can't read that email don't see the finding.

Ondatrace runs on Claude, from Anthropic. It treats the text of emails and messages as information to weigh. It never follows instructions written in them.

Why I built this

After years leading programs, I've found the hardest project problems rarely live in the project plan. They're spread across conversations and customer commitments. Ondatrace is my bet that AI can pull that picture together without adding another system to keep up to date.
